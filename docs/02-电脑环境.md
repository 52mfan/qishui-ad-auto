# 电脑环境安装

## 1. 安装 Python

1. 下载 [Python 3.9+](https://www.python.org/downloads/)（建议 3.10～3.12）
2. 安装时勾选 **Add python.exe to PATH**
3. 验证：

```bash
python --version
pip --version
```

## 2. 安装项目依赖

在项目目录下：

```bash
pip install -r requirements.txt
```

依赖说明：

| 包 | 用途 |
|----|------|
| opencv-python | 图像处理 |
| numpy | 矩阵运算 |
| rapidocr-onnxruntime | 中文 OCR 识别 |
| pillow | 图像显示（GUI） |
| pywin32 | Windows 命名管道（scrcpy 高帧率，可选） |
| av | H.264 解码（scrcpy，可选） |

## 3. 安装 adb（platform-tools）

**方式 A：官方 platform-tools（推荐）**

1. 下载 [platform-tools](https://developer.android.com/tools/releases/platform-tools)
2. 解压，例如放到 `C:\platform-tools`
3. 把该目录加入系统 **PATH**  
   或直接把 `adb.exe` 所在文件夹复制到本项目目录下的 `platform-tools\`

**方式 B：Android Studio**

安装 Android Studio 后，SDK 目录中自带 platform-tools，加入 PATH 即可。

验证：

```bash
adb version
adb devices
```

## 4.（可选）scrcpy 高帧率预览

见 README「可选：scrcpy」。没有 scrcpy 也能正常点击，只是预览约 1.5 FPS。

## 5. 常见问题

- **pip 很慢**：可换源  
  `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
- **python 不是内部命令**：安装时未加入 PATH，重新安装并勾选 Add to PATH
- **adb 不是内部命令**：未加入 PATH，或把 adb 放到项目 `platform-tools\` 下
