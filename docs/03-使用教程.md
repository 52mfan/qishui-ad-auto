# 使用教程

## 启动前

1. 手机 USB 调试已连接（`adb devices` 显示 `device`）
2. 手机打开 **汽水音乐** → 进入 **看广告领时长** 相关页面
3. 依赖已安装（`pip install -r requirements.txt`）

## GUI 版（推荐）

```bash
python qishui_ad_gui.py
```

### 界面说明

| 区域 | 作用 |
|------|------|
| 左侧实时影像 | 手机画面预览，命中框会标绿 |
| 右侧「重点识别」 | OCR 到的目标按钮与状态文字 |
| 手机信息 | 机型、Android 版本、分辨率、电量、充电、网络、IP |
| WiFi ADB | 无线连接：USB 点「开启无线」→ 填 IP 连接 |
| 运行统计 | 点击次数、轮次、用时 |
| 运行日志 | 点击、倒计时等待、错误信息 |

### 顶部按钮

- **启动 / 停止**：开始或结束自动点击
- **熄屏运行**：勾选后 scrcpy 会关闭手机屏幕仍继续推流点击
- **刷新设备**：重新检测 adb 设备
- **保存截图**：保存当前预览帧
- **清空日志**：清空右侧日志

### 推荐流程

1. 打开汽水音乐到「看广告」页面
2. 打开本程序，确认「手机信息」已显示机型
3. 点 **启动**
4. 观察日志：应出现 `点击「领取奖励」` 等记录
5. 离开电脑前确认已稳定点击几次

## 命令行版

```bash
python qishui_ad_bot.py
```

停止：`Ctrl+C`

## 行为说明

| 场景 | 程序行为 |
|------|----------|
| 出现「14秒后可领奖励」 | 休眠约倒计时秒数，再立刻探查「领取奖励」 |
| 出现「领取奖励」 | 优先点击（底部按钮，带随机抖动） |
| 出现「继续观看」 | 点底部按钮，避免点顶部同名 |
| 顶部「关注 / 更多直播」 | 立即返回，退出直播间 |
| 连续多次未命中 | 按返回防卡死（广告播放中不会误按） |

## 防检测

- 点击坐标随机偏移约 ±6 像素
- 点前随机延迟、点击间隔浮动
- 非固定节拍

## 常见问题

### 识别到了但不点

日志若有 `拒绝: xxx 出界`，说明按钮不在 ROI 内。  
编辑 `qishui_ad_gui.py` / `qishui_ad_bot.py` 中的 `TARGET_ROI`，放宽 `y` 范围（如 `0.10～0.98`）。

### 一直未命中

- 确认当前页面确实有「领取奖励」等按钮文案
- 日志「重点」一栏是否出现了目标文字
- 可点「保存截图」人工核对 OCR

### 点错位置

- 确认真机分辨率与日志中「帧(x,y)→机(x,y)」换算是否合理
- 不要使用与屏幕宽高比不符的强制分辨率

### 预览不动 / 很卡

- 未安装 scrcpy 时为截图模式，约 1.5 FPS，属正常
- 安装 scrcpy 后约 30 FPS
- 也可不看预览，只看日志判断是否在工作

### CMD 黑窗

- 请使用 PyInstaller `--windowed` 打包的 GUI exe
- 脚本内 adb 调用已加 `CREATE_NO_WINDOW`
