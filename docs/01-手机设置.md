# 手机设置（只需一次）

## 1. 打开开发者选项

1. 打开 **设置 → 关于手机**
2. 连续快速点击 **版本号** 7 次
3. 提示「已开启开发者模式」即可

## 2. 开启 USB 调试

1. 返回 **设置 → 系统 / 更多设置 → 开发者选项**
2. 打开：
   - **USB 调试**（必开）
   - **USB 调试（安全设置）** 或 **允许模拟点击**  
     （小米 / vivo / OPPO 等机型必开，否则脚本只能看、不能点）
3. 用数据线连接电脑
4. 手机弹出「允许 USB 调试吗？」→ 勾选 **一律允许** → 确定

## 3. 验证连接

电脑打开命令行（cmd / PowerShell）：

```bash
adb devices
```

应看到类似：

```
List of devices attached
xxxxxxxx    device
```

- 若是 `unauthorized`：在手机上点允许调试
- 若是空列表：换数据线 / 换 USB 口 / 重装驱动

## 4. 保持不休眠（推荐）

开发者选项中：

- **充电时屏幕不休眠**（可选）
- 或由脚本自动执行 `svc power stayon true`

## 5. 小米手机补充

- 开发者选项 → **USB 调试（安全设置）** 需登录小米账号后开启
- 部分机型需在 **开发者选项** 中关闭 **MIUI 优化**（若点击无效可尝试）

## 6. 屏幕与音量

- 看广告期间建议 **屏幕常亮**（GUI 可勾选「熄屏运行」用 scrcpy 熄屏挂机）
- 音量过低可能导致部分任务不计时长，保持媒体音量在中等以上
